# 🏡 Wanderlust-Property Rental Application

A full-stack Airbnb-inspired web application that allows users to explore and browse different property listings across various categories and destinations.

The application provides a clean and user-friendly interface with property cards, destination search, category navigation, pricing information, and more.

---

## ✨ Features

- 🏠 Browse property listings
- 🔍 Search destinations
- 🗂️ Browse properties by category
- 💰 View property prices per night
- 🧾 Option to display total price after taxes
- 🖼️ Display property images
- 📱 Responsive and user-friendly interface
- 🔐 Sign Up and Log In interface
- ☁️ Cloud-based image configuration
- 🧩 MVC-based project architecture
